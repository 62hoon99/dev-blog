# **📘 GOF 디자인 패턴 학습 기록**

  

> **인프런 [GOF 디자인 패턴](https://www.inflearn.com/course/%EB%94%94%EC%9E%90%EC%9D%B8-%ED%8C%A8%ED%84%B4/dashboard) 강의를 수강하며 학습한 내용을 정리한 저장소입니다.**
  

이 저장소는 GOF 디자인 패턴을 **암기가 아닌 설계 관점**에서 이해하는 것을 목표로 합니다.

각 패턴이 _어떤 문제를 해결하는지_, _언제 사용해야 하는지_에 집중해 정리합니다.

---

## **📌 학습 목표**

- GOF 디자인 패턴 23개의 **의도와 사용 맥락** 이해
    
- 객체 지향 설계 원칙(SOLID)과 패턴의 연결
    
- 실무 코드(Spring 기반)에서 패턴을 식별하고 적용
    

---

## **📂 학습 내용 구성**

### **생성(Creational) 패턴**

- 객체 생성 책임 분리와 유연한 인스턴스 생성
    
### **구조(Structural) 패턴**

- 기존 코드 변경 없이 구조 확장 및 조합
    
### **행위(Behavioral) 패턴**

- 객체 간 책임 분리와 협력 방식 개선
