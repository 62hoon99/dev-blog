> 인스턴스를 오직 한개만 제공하는 클래스
# 싱글톤 구현 방법

## 1. 이른 초기화 방법

**코드**
``` Java
public class Settings {  
    private static final Settings instance = new Settings();  
      
    private Settings() {}  
      
    public static Settings getInstance() {  
        return instance;  
    }  
}
```

**특징**
- 프로그램 실행 중 JVM이 클래스를 로딩할 때 인스턴스가 생성된다. (불필요하게 사용하지도 않는데 생성될 수 있음)
- thread safe 하다.

## 2. Double Checked Locking

**코드**
``` Java
public class Settings {  
    private static volatile Settings instance;  
  
    private Settings() {}  
  
    public static Settings getInstance() {  
        if (instance == null) {  
            synchronized (Settings.class) {  
                if (instance == null) {  
                    instance = new Settings();  
                }  
            }  
        }  
        return instance;  
    }  
}
```

**특징**
- 지연 로딩. 인스턴스를 사용하는 시점에 로딩된다.
- synchronized 키워드를 인스턴스 생성 시점에만 쓰기 때문에 synchronized 키워드를 메서드 단위로 쓰는 것 보다 성능에 이점이 있다.
- volatile을 쓰는 이유
