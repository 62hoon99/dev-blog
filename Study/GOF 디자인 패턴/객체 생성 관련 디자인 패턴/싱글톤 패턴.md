# 싱글톤 구현 방법

## 1. 이른 초기화 방법

**코드**
``` Java
public class Settings {  
    private static final Settings instance = new Settings();  
      
    private Settings() {}  
      
    public static Settings getInstance() {  
        return instance;  
    }  
}
```

**특징**
- 프로그램 실행 중 JVM이 클래스를 로딩할 때 인스턴스가 생성된다. (불필요하게 생성될 수 있음)
