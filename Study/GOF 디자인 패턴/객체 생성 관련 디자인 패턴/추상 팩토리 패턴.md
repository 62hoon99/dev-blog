> 서로 관련있는 여러 객체를 만들어주는 인터페이스

# 추상 팩토리 패턴이란?

- **서로 관련 있거나 의존 관계에 있는 객체들의 집합**을 생성하기 위한 인터페이스를 제공하는 패턴이다.
- 구체적인 클래스에 의존하지 않고, **제품군(Product Family)** 단위로 객체를 생성할 수 있도록 한다.
- 클라이언트 코드는 어떤 구체 팩토리를 사용하는지 알 필요 없이, **일관된 객체 조합**을 사용할 수 있다.

## 추상 팩토리 패턴이 필요한 경우

- 객체 A, B, C가 **서로 호환되어야 하는 경우**
- 구현체 조합이 여러 개 존재하는 경우
- 특정 구현 세트를 **통째로 교체**하고 싶을 때

이런 상황에서 객체를 각각 new로 생성하면 잘못된 조합이 생기기 쉽고, 변경 범위도 커진다.

## 팩토리 메서드 패턴과의 차이점

| **구분** | **팩토리 메서드**            | **추상 팩토리**                  |
| ------ | ---------------------- | --------------------------- |
| 생성 대상  | 하나의 객체                 | 관련된 객체들의 집합                 |
| 초점     | 객체 생성의 **확장**          | 객체 조합의 일관성                  |
| 구조     | 상속 기반 (메서드 오버라이딩)      | 구성 기반 (팩토리 객체 교체)           |
| 확장 방식  | 새로운 Product → 서브클래스 추가 | 새로운 Product Family → 팩토리 추가 |
| 사용 목적  | 생성 로직 분리               | 구현 세트 통째로 교체                |

# 추상 팩토리 패턴 구현 예시

## Factory
``` Java
// 팩토리 메서드 패턴과 동일
public interface ShipFactory {  
  
    default Ship orderShip(String name, String email) {  
        validate(name, email);  
        prepareFor(name);  
        Ship ship = createShip(name);  
        sendEmailTo(email, ship);  
        return ship;  
    }  
  
    private void sendEmailTo(String email, Ship ship) {  
        System.out.println("주문하신 배 " + ship + "의 완료 정보를 " + email + "로 보냅니다.");  
    }  
  
    Ship createShip(String name);  
  
    private void validate(String name, String email) {  
        if (name == null || name.isBlank()) {  
            throw new IllegalArgumentException("배 이름을 지어주세요.");  
        }  
        if (email == null || email.isBlank()) {  
            throw new IllegalArgumentException("연락처를 남겨주세요.");  
        }  
    }  
  
    private void prepareFor(String name) {  
        System.out.println(name + " 만들 준비 중");  
    }  
  
}


public class WhiteShipFactory implements ShipFactory {  
  
    private final ShipPartsFactory shipPartsFactory;  
  
    public WhiteShipFactory(ShipPartsFactory shipPartsFactory) {  
        this.shipPartsFactory = shipPartsFactory;  
    }  
  
    @Override  
    public Ship createShip(String name) {  
        return new WhiteShip(name, "white", "흰 배",  
                shipPartsFactory.createWheel(), shipPartsFactory.createAnchor());  
    }  
}
```

## Ship
``` Java
public abstract class Ship {  
    protected String name;  
    protected String color;  
    protected String description;  
    protected Anchor anchor;  
    protected Wheel wheel;  
  
    public Ship(String name, String color, String description, Anchor anchor, Wheel wheel) {  
        this.name = name;  
        this.color = color;  
        this.description = description;  
        this.anchor = anchor;  
        this.wheel = wheel;  
    }  
  
    @Override  
    public String toString() {  
        return description + "anchor class: " + anchor.getClass() + " wheel class: " + wheel.getClass();  
    }  
}

public class WhiteShip extends Ship {  
    public WhiteShip(String name, String color, String description, Wheel wheel, Anchor anchor) {  
        super(name, color, description, anchor, wheel);  
    }  
}
```
