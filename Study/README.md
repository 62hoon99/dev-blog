# ✏️ Study

> 개발자로 성장하기 위해 학습한 내용을 정리하는 공간입니다.  단순히 읽고 끝나는 것이 아니라, **이해한 내용을 나만의 언어로 정리하고 실무에 적용할 수 있도록 체화하는 것**을 목표로 합니다.

## 📚 정리 기준
- 단순 요약이 아니라 “왜 그런지” 이해 중심으로 기록
- 실무에서 쓸 수 있는 내용 위주 정리
- 필요할 때 다시 참고할 수 있도록 구조화된 기록

## 📂 디렉터리 구조
- `대규모 시스템 설계`
  - 시스템 설계 역량 향상을 위한 학습 기록
- `읽기 좋은 코드`
  - 코드 가독성과 유지보수성을 높이기 위한 내용 정리
- `토비의 스프링 부트`
  - 스프링 기반 아키텍처 및 내부 동작 원리 이해 정리
- Web
  - Web 관련 학습 내용 정리

> 시간이 지나도 다시 꺼내 봤을 때 도움이 되는 학습 기록을 목표로 합니다.
