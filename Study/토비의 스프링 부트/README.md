# 🍃 토비의 스프링 부트: 이해와 원리 학습 기록

> **인프런 이일민(토비) 님의 [토비의 스프링 부트 - 이해와 원리](https://www.inflearn.com/course/%ED%86%A0%EB%B9%84-%EC%8A%A4%ED%94%84%EB%A7%81%EB%B6%80%ED%8A%B8-%EC%9D%B4%ED%95%B4%EC%99%80%EC%9B%90%EB%A6%AC) 강의를 듣고 학습한 내용을 정리한 저장소입니다.**

이 프로젝트는 스프링 부트가 제공하는 편리함 뒤에 숨겨진 **핵심 동작 원리**를 파악하고, 직접 스프링 부트의 기능을 밑바닥부터 구현해보며 학습하는 것을 목표로 합니다.

---

## 📌 학습 목표
- 스프링 부트의 핵심 기능을 직접 만들어보며 동작 원리 이해하기
- **Containerless** 웹 애플리케이션 아키텍처의 개념 파악
- 스프링 프레임워크의 활용법과 객체 지향 설계 원칙(SOLID)의 적용
- 자동 구성(Auto Configuration)과 조건부 빈 등록(Conditional)의 메커니즘 습득

## 📂 주요 학습 내용

1. [스프링 부트 살펴보기](1주차%20섹션0%20~%20섹션2.md)
	- 스프링 부트의 철학과 목표 (Opinionated, Containerless)
	- 독립 실행형(Standalone) 애플리케이션의 구조

2. [스프링 부트 시작하기](2주차%20섹션3%20~%20섹션4.md)
	- 내장 톰캣(Embedded Tomcat)의 원리
	- 서블릿 컨테이너와 스프링 컨테이너의 통합 과정

3. [DI와 테스트, 디자인 패턴](3주차%20섹션5%20~%20섹션6.md)
	- 의존관계 주입(DI)을 통한 유연한 설계
	- 단위 테스트와 통합 테스트 작성법
	- 전략 패턴, 데코레이터 패턴 등 실무적인 디자인 패턴 적용

4. [자동 구성(Auto Configuration)](4주차%20섹션7%20~%20섹션8.md)
	- @Conditional 을 이용한 조건부 빈 등록 원리
	- 스프링 부트가 인프라 빈을 자동으로 구성하는 방식 이해

5. 서비스 추상화와 데이터 액세스
	- 스프링의 서비스 추상화(PSA) 적용
	- JdbcTemplate을 활용한 데이터 접근 기술 학습
