# 읽기 좋은 코드

이 디렉터리는 **가독성이 좋고 유지보수가 쉬운 코드**를 작성하기 위한 학습 내용을 정리합니다.  
여러 책과 자료를 기반으로, 실무 코드에 적용할 수 있는 원칙과 패턴을 중심으로 기록합니다.

## 📚 정리 대상
- 읽기 쉬운 코드 작성 원칙
- 좋은 코드 스타일과 나쁜 코드 스타일 비교
- 실무 코드에 적용 가능한 사례 중심 정리
- 책 내용 요약 + 개인적인 해석과 경험 추가

## 📂 포함된 내용
- `읽기 쉬운 코드_마크 시먼`
- `코드 작성 가이드_이시가와 무네토시`
- `클린 코드_로버트 C. 마틴`

## 🎯 목표
- “돌아가는 코드”가 아니라  
  **“읽기 쉽고 변경하기 쉬운 코드”를 작성하는 개발자 되기**
- 나뿐만 아니라 협업하는 동료에게도 친절한 코드 작성하기
